# Public-data helium prediction: reproducibility package

Frozen release: 2026-10-08, corrected-input and API10-purged experiments.

This repository reproduces the principal CatBoost experiments for natural helium
across the conterminous United States. It contains the actual final model inputs,
original public tabular observations, source attribution, exact train/test indices,
model settings, a portable CPU runner, and reference results. No commercial well
database, account credentials, manuscript, reviewer correspondence, or local
Python environment is included.

## Scope and reproducibility boundary

**Self-contained:** validate source-record linkage; reproduce the primary
25-predictor model, five spatial folds, 50 grouped holdouts, 50 surface-only spatial
holdouts and one full-data surface model; recalculate held-out/OOB metrics,
grid-cell uncertainty and four screening classes; recalculate national and
basin-level SHAP rankings and permutation importance.

**Frozen upstream products:** stratigraphic mapping, polygon attribution and
regional raster preprocessing are supplied as audited, versioned inputs. Original
tabular source snapshots, stratigraphic crosswalks and the aligned raster layers
are included. The large original regional raster/vector downloads are identified
in `sources/source_manifest.csv` and `sources/original_files.csv`; they are not
all bundled. This is NOT a one-command reconstruction from newly downloaded raw
geospatial data. No live web service or source download is needed for the learning
experiments. Exact publication artwork/layout is not regenerated by this package.

## Quick start

Use a 64-bit Python environment. The verified original environment is Python
3.9.25 on Windows; package versions are pinned in `requirements.txt`. Python 3.9
is retained here for historical reproduction, not recommended as a general new
deployment environment. Later Python/library versions can produce different trees
or numerical results and are not claimed to be bitwise identical.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
python -m pip install -r requirements.txt
python src/reproduce.py validate
python src/reproduce.py train --experiment primary
python src/reproduce.py interpret
```

Run all experiments and aggregate them:

```bash
python src/reproduce.py train --experiment all --threads 8
python src/reproduce.py summarize
```

Individual experiment selections are `national`, `grouped`, `surface`, or an
exact name such as `surface_01`. There are 107 fits in total. The runner is serial
across fits and uses up to eight CPU threads per fit. Full training takes
substantially longer than the single-model verification and may require several
GB of memory and output storage. Compatible cached fits in `results/` are reused;
delete that output folder manually if an entirely fresh run is desired.

The included release test report states which commands were actually rerun.
It does not imply that all 107 models were retrained while packaging.

## Files

- `data/processed/wells.csv.gz`: 10,286 final records, 25 predictors, target,
  identifiers, coordinates and split metadata. Only predictors explicitly listed
  in `config/study.json` enter CatBoost.
- `data/processed/grid.csv.gz`: 78,057 10-km grid cells, 20 regional predictors,
  grid coordinates and nearest-observed-well distance.
- `data/splits/indices.npz`: exact **post-purge** train/test row indices for each
  fit, with record and grid IDs to guard against row-order changes.
- `data/feature_dictionary.csv`: predictor types, source families and coverage.
- `data/raw/`: original public helium, natural-gas, produced-water and Macrostrat
  snapshots plus available source metadata. `.gz` files preserve original bytes
  after decompression. Ancillary databases supply stratigraphic metadata, not
  hydrogeochemical model predictors.
- `data/provenance/`: state/global formation crosswalks and record-level mapping
  provenance for the selected records.
- `data/aligned_rasters/`: final 4-km EPSG:5070 local and regional mean rasters,
  useful for auditing spatially sampled inputs; not original source rasters.
- `reference/`: expected metrics, point/grid predictions, category mappings,
  importance tables and selected final follow-up tables. These are comparisons,
  never inputs to model fitting.
- `sources/`: dataset citations, download landing pages, source hashes and
  preprocessing notes. Hashes identify the snapshots actually used, not files
  that may subsequently change on remote servers.
- `checksums.sha256`: SHA-256 for every release file except the checksum file.

## Data and units

`source_row_id` is the zero-based row in the original helium CSV, excluding its
header; `helium_record_id = source_row_id + 1`. API10 values are strings with
leading zeros and must not be converted to numeric IDs. There are 9,345 distinct
API10 identifiers and 9,359 distinct longitude/latitude pairs; these are different
counts, not interchangeable definitions of wells.

The regression target is `log10_helium_mol_percent = log10(He in mol%)`.
Thus -2, -1, 0 and 1 correspond to 0.01, 0.1, 1 and 10 mol%, respectively.
R-squared, MAE and RMSE are calculated in log10 space unless explicitly named
`mae_mol_percent`. Original-scale MAE is recomputed from the two back-transformed
vectors, **not** obtained by exponentiating log-space MAE. Depth is in feet,
gravity in mGal, magnetics in nT, K in percent, eU/eTh in ppm, elevation in meters,
and boundary/fault/well distances in kilometers. Negative elevations are retained.
Blank numeric cells mean missing, not zero. Categorical ages are labels, not
continuous ages in Ma.

## Model and validation rules

The 25-predictor model includes depth, formation, stratigraphic era, period and
epoch. The 20-predictor model excludes these five. Coordinates and identifiers
are used for linkage, grouping and map display only. Numeric missing values are
handled by CatBoost; rare categories are mapped using **training-only** counts
(minimum 10 records), retaining observed UNKNOWN/AMBIGUOUS/OUTSIDE special labels.
Unseen test/grid categories become OTHER_RARE.

All fits use 600 iterations, depth 8, learning rate 0.05, L2 leaf regularization
5, RMSE loss, random strength 0.5 and model seed 42. No tuning or retuning is
performed by this package. Grouped refits use split seeds 0-49. The 50 spatial
refits originate from GroupShuffleSplit with seed 260927. Exact stored splits,
rather than regenerated random splits, are authoritative. Training records with
an API10 present in a held-out subset were purged before fitting. Entire
100 x 100 km blocks are withheld for spatial runs; opposite sides of a block
boundary need not be 100 km apart.

OOB means and sample standard deviations use only the fits withholding each
record; dispersion analysis requires at least five predictions. Grid-cell
uncertainty uses the standard deviation across all 50 surface spatial refits
(ddof=1). It measures sensitivity to training-block composition, not a calibrated
prediction interval or total geological uncertainty. The saved 5th/95th
percentiles are descriptive ensemble percentiles, not calibrated coverage bounds.

## Expected core results

| Evaluation | R-squared | MAE, log10 units |
|---|---:|---:|
| Primary grouped holdout | 0.890284 | 0.155839 |
| Pooled five-fold spatial validation | 0.725984 | 0.241843 |
| Surface spatial OOB, at least 5 predictions | 0.655320 | 0.281155 |

The 34,697 grid cells within 100 km of an observation define the support mask.
High He means ensemble-median He >= 0.3 mol%; lower instability means SD <= the
median SD within that mask (0.08524748896062527 log10 units). The expected counts
are S1 high/lower 1,046; S2 high/higher 2,871; S3 low/lower 16,303; S4 low/higher
14,477. Outside-mask cells are class 0, not low-potential cells. The concentration
threshold is operational, not an economic cutoff. The grid supports regional
follow-up, not depth-specific resource estimates or drilling decisions.

## Known limitations

- Source snapshots contain clustered observations, ambiguous stratigraphic
  assignments and rounded concentrations. They are not independent random samples
  of all possible subsurface reservoirs.
- API10 0304710581 has a reported cross-source He discrepancy (0.16 versus
  0.016 mol%). The public helium release is retained as the primary target source;
  no silent correction is made. The recorded sensitivity check is included.
- Regional averaging is a 51 x 51-cell square on a 4-km grid, not a circular
  100-km-radius kernel. The support radius and spatial-block size are separate
  design choices. None guarantees generalization or calibrates uncertainty.
- Supplementary follow-up tables are preserved for audit; the portable runner
  reproduces core training, metrics, uncertainty, scenarios and primary importance,
  not every additional sensitivity analysis or exact figure composition.
